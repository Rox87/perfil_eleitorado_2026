
O dashboard já está pré processado, para visualizar basta executar:  
`python scripts/serve.py`


Para extrair os dados, e executar a extração vc mesmo, baixe os arquivos CSV de **Eleitorado - 2026** em:  
https://dadosabertos.tse.jus.br/dataset/eleitorado-2026

Deixe os arquivos na pasta dados descompactados e execute
`python scripts/extract_data.py`
